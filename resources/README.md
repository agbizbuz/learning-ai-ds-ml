# 📚 Curated Learning Resources

This directory contains curated resources organized by difficulty level to support your AI/ML learning journey.

## 🎯 Beginner Resources

**Focus:** Fundamentals, basic algorithms, and hands-on practice

### Recommended Topics:
- Python programming
- Basic statistics and linear algebra
- Data exploration with pandas
- Simple ML algorithms (linear regression, decision trees)

### Key Resources:
1. **Python for Beginners**
   - [W3Schools Python Tutorial](https://www.w3schools.com/python/)
   - [Python Official Documentation](https://docs.python.org/3/tutorial/)

2. **Data Science Fundamentals**
   - [Pandas Documentation](https://pandas.pydata.org/docs/)
   - [NumPy Tutorial](https://numpy.org/doc/stable/user/quickstart.html)

3. **Machine Learning Basics**
   - [Scikit-learn Tutorial](https://scikit-learn.org/stable/tutorial/index.html)
   - [Google ML Crash Course](https://developers.google.com/machine-learning/crash-course)

## 💼 Intermediate Resources

**Focus:** Advanced algorithms, model evaluation, and real-world applications

### Recommended Topics:
- Deep learning fundamentals
- Model optimization techniques
- Advanced NLP and computer vision
- Time series analysis

### Key Resources:
1. **Deep Learning**
   - [TensorFlow Tutorials](https://www.tensorflow.org/tutorials)
   - [PyTorch Documentation](https://pytorch.org/tutorials/)

2. **Advanced ML Techniques**
   - [XGBoost Documentation](https://xgboost.readthedocs.io/)
   - [LightGBM Tutorials](https://lightgbm.readthedocs.io/)

3. **NLP & Computer Vision**
   - [Hugging Face Transformers](https://huggingface.co/transformers/)
   - [OpenCV Python Tutorials](https://docs.opencv.org/4.x/d6/d00/tutorial_py_root.html)

## 🎓 Advanced Resources

- **Intermediate:** "Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow" by Aurélien Géron
- **Advanced:** "Deep Learning" by Ian Goodfellow, Yoshua Bengio, Aaron Courville

### Courses:

- [Kaggle](https://www.kaggle.com/) - Competitions and datasets

2. **Intermediate Phase:** Build projects that solve real problems
