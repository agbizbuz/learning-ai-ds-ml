## ✅ What You Should Be Able To Do After This Section

- Write Python functions and use list/dict comprehensions
- Load a CSV, clean missing values, and reshape a DataFrame
- Split data into train/test sets
- Train a baseline model (e.g. Random Forest) and evaluate with accuracy / R²
- Visualise distributions, correlations, and decision boundaries with Matplotlib / Seaborn
